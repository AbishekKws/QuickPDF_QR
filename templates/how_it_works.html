How it works

From your file to their phone in three steps

No accounts, no app installs and no email attachments. Everything happens on one shared download page that a QR code opens.

  1. 1

    Add your files

    Open a tool and drop in what you have: PDFs to share, or images, spreadsheets and text to convert. Everything is checked before upload, so the format and the {{ config.MAX_CONTENT_LENGTH // 1048576 }} MB limit are clear upfront.

  2. 2

    Get the QR code

    The files are bundled, a ZIP is prepared and a QR code is generated right away. Open the code on screen, print it, or send the link like any other URL.

  3. 3

    Scan and download

    Scanning opens the download page. Each file has its own button, and one more button takes the whole bundle as a ZIP — no sign-in, works on any phone camera.
